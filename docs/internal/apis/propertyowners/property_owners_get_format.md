# Property owners: GET

Back to the [overview](./property_owners.md). Authentication, the common errors and the period model are described there.

## The owner object
GET, POST and both PATCH routes answer with this shape:

| Field | Type | Notes |
| ----- | ---- | ----- |
| `id` | string (UUID) | Generated by the database |
| `host_id` | string | Cognito `Username` of the host |
| `first_name` | string | |
| `last_name` | string | |
| `company_name` | string or `null` | |
| `email` | string | |
| `phone` | string or `null` | |
| `preferred_language` | string or `null` | Such as `en` or `nl-NL` |
| `owner_type` | string | `individual`, `company` or `trust` |
| `status` | string | `active`, `inactive`, `pending` or `archived` |
| `notes` | string or `null` | |
| `owner_user_id` | string or `null` | Always `null` for now. Reserved for an owner with their own Domits login |
| `created_at` | number | Epoch milliseconds |
| `updated_at` | number | Epoch milliseconds |
| `properties` | array | The owner's **current** periods, see below |

Each entry of `properties`:

| Field | Type | Notes |
| ----- | ---- | ----- |
| `property_id` | string | |
| `property_title` | string or `null` | `null` when the property no longer exists for this host |
| `ownership_basis_points` | number | 1 to 10000 |
| `effective_from` | number | UTC midnight, epoch milliseconds |
| `effective_to` | number or `null` | Exclusive end, `null` while open |

`properties` holds only periods that are current today, ordered by `effective_from` and then by creation time. Upcoming periods are not included. All titles of one response come from a single query.

## List owners

`GET {baseUrl}`

Headers: `Authorization: <Cognito access token>`

No body. No query parameters, apart from ones the router ignores.

Returns every owner of the caller's host, archived owners included, ordered by `last_name` and then `first_name`. An owner without a current period gets `"properties": []`.

### Responses

`200`, an array of owner objects. Empty array when the host has no owners.

  {
    "id": "3f2b8c1e-9a4d-4e6f-8b7a-1c2d3e4f5a6b",

    "first_name": "Anna",
    "last_name": "de Vries",
    "company_name": null,
    "email": "anna@example.com",
    "phone": "+31 6 12345678",
    "preferred_language": "nl-NL",
    "owner_type": "individual",

## Read one owner

`GET {baseUrl}?id={ownerId}`

Headers: `Authorization: <Cognito access token>`

No body.

| Query | Rules |
| ----- | ----- |
| `id` | Required. A UUID, any letter case |

### Responses

`200`, one owner object, in the shape shown above.

| Status | Message | When |
| ------ | ------- | ---- |
| 400 | `A valid owner id is required.` | `id` is empty or not a UUID. Checked before any database read |
| 404 | `Owner not found.` | No owner with this id for the caller's host, including an owner of another host |
| 401, 403, 405, 500 | see the [overview](./property_owners.md#common-responses) | |
