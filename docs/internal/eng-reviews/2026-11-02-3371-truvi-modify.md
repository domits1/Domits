## Failure modes

| Code path | Realistic failure | Test | Handling | Visible to the user |
|---|---|---|---|---|
| modify run | Truvi timeout or 5xx | yes | not saved, `updatedat` moves the row back, tried next run | no, retried |
| modify run | unexpected 400 | yes | in `errors` of the summary, row moves back | yes, the run reports an error |
| modify run | Truvi refuses (check-in in the past, cancelled) | yes | dates saved with the reason, not sent again | no |
| modify run | only the time of day changed | yes | no Truvi call, dates saved | no |
| modify run | saving one booking fails | yes | next booking goes on, error in the summary | yes |
| `markAttempt` | database down | no | counted as an error in the summary | yes, the run fails |
